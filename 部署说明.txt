index.html
manifest.webmanifest
sw.js

icons/icon-192.png
icons/icon-512.png

一、先解压 ZIP
请不要把 ZIP 本身上传成一个文件。先在电脑/手机解压，保持上面的目录结构。

二、在 GitHub 新建仓库
1. 登录 github.com。
2. 新建一个 Repository。
3. 建议仓库名：word-game
4. 建议设为 Public。
5. 创建仓库。

三、上传游戏文件
进入刚建立的 word-game 仓库：
Add file → Upload files
把本压缩包解压后的全部文件和 icons 文件夹一起上传。
然后点 Commit changes。

四、打开 GitHub Pages
仓库 → Settings → Pages
Build and deployment：
Source 选择 “Deploy from a branch”
Branch 选择 “main”
Folder 选择 “/(root)”
点 Save。

五、打开游戏
等待 GitHub Pages 完成发布后，地址一般是：
https://你的GitHub用户名.github.io/word-game/

一定要从这个 https:// 地址打开。
不要再从 Android 下载目录的 content://downloads... 地址打开，否则麦克风权限可能无法工作。

六、第一次启用麦克风
进入游戏首页 → “跟读麦克风” → “启用/测试麦克风”
Chrome 弹出“允许此网站使用麦克风？”时选择“允许”。

如果曾经点过“禁止”：
Chrome 地址栏左侧的网站信息 → 权限 → 麦克风 → 允许
或者：
Chrome → 设置 → 网站设置 → 麦克风 → 找到该 GitHub Pages 网站 → 允许。

七、安装到手机桌面
发布成 HTTPS 后，游戏支持 PWA。
游戏会出现“安装到桌面”，也可以 Chrome 右上角 ⋮ → “添加到主屏幕”/“安装应用”。

说明：
- 学习进度、金币、等级、错词本保存在当前浏览器本机。
- 清除 Chrome 网站数据会清除这些本地进度。
- 页面和教材词库可离线缓存；语音识别是否能离线工作取决于手机 Chrome/系统语音服务。
