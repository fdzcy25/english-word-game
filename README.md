# 单词勇者岛 · V15

V15 基于 V14，重点调整跟读操作和 Android Google 美式音色的稳定性。

## 跟读按钮整合
- 不再显示单独的“停止录音”按钮。
- 第一次点击跟读麦克风：开始录音，并在原按钮上显示“录音中”。
- 第二次点击同一个麦克风按钮：结束录音并进入回放/纠音。
- 独立“跟读之桥”和答题后的“单词跟读”两处统一采用相同操作。
- 最长录音仍保留 12 秒自动结束保护。
- V14 的 iOS 15.8.x MP4/AAC 录音及旧 Safari 回放兼容继续保留。

## Android Google en-US 音色恢复
- 保留 V14 的“Android 优先 Google en-US；iPhone 默认跟随系统 en-US”逻辑。
- Android 在页面启动、重新获得焦点、页面恢复可见、首次触摸、TTS 播放结束、voiceschanged 后都会继续扫描。
- 当 `speechSynthesis.getVoices()` 偶发返回空列表时，不清除本轮已经拿到的可用音色对象。
- 后台最多持续约 60 秒低频重试；一旦 Google en-US 重新公开就自动恢复。
- “刷新设备音色”在 Android 空列表时会额外轻量唤醒一次 TTS 引擎，再继续扫描。
- 保存“上一次成功检测到的 Google en-US 音色名称”用于诊断；注意它只是诊断信息，只有浏览器本轮重新返回真实 voice 对象后网页才能强制指定该音色。

## iPhone / iPad
- 继续默认“🍎 跟随 iPhone 系统美式音色（推荐）”。
- 继续兼容系统中已选的 Allison（优化音质）等声音：网页只请求 `en-US`，不强制指定 Safari 未公开的 voice。
