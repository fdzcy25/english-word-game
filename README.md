# 单词勇者岛 · V12

V12 在 V11 的录音回放基础上新增 iOS / Android 双平台美式英语音色管理。

- iPhone / iPad：自动识别 iOS/iPadOS，优先 Apple en-US 音色。
- Android：继续优先 Google en-US 音色。
- 当前浏览器实际公开的所有 en-US 音色都会列出，可逐个“选择并试听”。
- 用户选择会保存在本机，下次打开继续使用。
- 首页试听、背词朗读、答题喇叭、跟读标准发音全部共用同一个选中音色。
- 继续保留 V11 的多轮 getVoices() 扫描、voiceschanged 监听、诊断详情和录音回放。
