# 单词勇者岛 V11

V11 在 V10 已成功的“录音 → 显式停止 → 回放”基础上，重点修复 Android/Chrome 音色枚举不稳定问题。

- 保留 V6 的 Web Speech TTS 发音方式。
- 不使用静音唤醒，不额外抢占 TTS。
- getVoices() 偶发返回空数组时，不再清掉上一轮已找到的音色。
- 页面启动、voiceschanged、回到页面、首次触摸、每次真正发音前都会重新扫描。
- “刷新手机音色”会连续扫描约 4 秒。
- 新增“音色检测详情”，可看到浏览器实际公开的全部音色数量、en-US 数量、Google 数量和前 12 个音色名称。
- 跟读录音、停止按钮、录音回放继续保留。当前浏览器若没有 SpeechRecognition，则不会伪造自动发音评分。
