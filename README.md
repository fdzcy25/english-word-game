# 单词勇者岛 V10

北师大版（三年级起点·旧版）小学英语闯关学习 PWA。

V10 以 V6 为母版：保留 V6 已验证的美式 TTS / Google 音色逻辑，只新增跟读录音、显式停止、录音回放和自动纠音。

## V10 重点

- 恢复 V6 原版 TTS：试听、标准发音喇叭、单词自动发音使用同一套 speak()。
- 不再使用 V9 的 speechSynthesis 静音唤醒、resume 或额外扫描覆盖。
- 跟读使用 MediaRecorder 真正录音。
- 录音时显示红色“停止录音”按钮。
- 停止后可立即播放自己的录音，并与标准发音对比。
- 自动语音识别可用时显示识别结果、匹配度、美式参考音标与纠音建议。
- 自动识别不可用时仍保留录音和回放，并显示真实错误码，不把识别失败误判成发音错误。
- 页面底部显示 `单词勇者岛 · V10`。

部署时请把压缩包内全部文件覆盖到 GitHub Pages 仓库并提交。
